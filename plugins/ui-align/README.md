# BB UI Align

Выравнивает кнопки истории, переключатель боковой панели и переключатель правой панели с системными кнопками окна macOS при увеличенном масштабе BB. По отдельному переключателю переносит заголовок беседы и все его действия в свободное место верхней панели.

Коррекция выравнивания сохраняет масштаб текста и элементов, высоту шапки и области перетаскивания. Реагирует на масштабирование, размер окна и замену шапки. В полноэкранном режиме, браузере, Windows и Linux коррекция не применяется. При отключении или перезагрузке плагина удаляет свои стили, наблюдатели и обработчики.

Настройки: **Settings → Installed plugins → UI Align**. Можно отключить коррекцию или задать точную вертикальную поправку (−10…10 пунктов macOS). Настройки применяются сразу.

**Компактная шапка беседы** по умолчанию выключена. При включении заголовок, меню, действия рабочего каталога и Git, кнопки плагинов и панели размещаются между существующими элементами верхней полосы. Прежняя строка освобождает свою высоту (48 CSS-пикселей в стандартном BB). Длинное название сокращается многоточием. Режим не зависит от выбранной темы и переключателя выравнивания кнопок.

Режим действует при наличии верхней полосы BB, ширине окна от 768 CSS-пикселей и точном указателе. В разделённом экране, при нехватке места или неподдерживаемой структуре интерфейса плагин возвращает обычную шапку. Кнопки и панели, которые добавляют другие плагины в верхнюю полосу, также занимают место: компактная шапка использует оставшийся промежуток.

Плагин меняет положение существующего заголовка через CSS. Он сохраняет его DOM-родителей и обработчики BB. Переименование, меню и действия остаются нативными. При отключении режима или плагина исходная компоновка восстанавливается.

Плагин рассчитан на шапку BB 0.46, её DOM и CSS-переменную `--bb-macos-chrome-control-y`. После изменений шапки в новых версиях BB селектор может потребовать обновления. Центр нативных кнопок принят за 25 пунктов от верхнего края (позиция 18 + радиус 7); точная поправка позволяет учесть отличия macOS.

```sh
cd plugins/ui-align
npm ci
npm run typecheck
npm run build
bb plugin install path:. --yes
```

Команды выполняются из корня репозитория. Установка из корня без перехода в каталог плагина: `bb plugin install path:. --plugin ui-align`.

После правок: `bb plugin build && bb plugin reload ui-align`, либо `bb plugin dev`.

Отключение: `bb plugin disable ui-align`.

Диагностика: `bb ui-align status` показывает коэффициент масштаба и измеренный центр кнопок из последнего окна BB. Поле `compactHeader` содержит состояние компактной шапки: `enabled`, `active`, `reason` и `availableWidth` в CSS-пикселях. Возможные причины: `disabled`, `no-title-bar`, `no-thread`, `split-layout`, `compact-viewport`, `unsupported-layout`, `not-enough-space`, `active`. Плагин отправляет локальному серверу геометрию и состояние шапки, без содержимого тредов. Значения не сохраняются на диск.

`tests/fixture.html` — проверка настоящего CSS и жизненного цикла в браузере: разные коэффициенты масштаба, настройки, полноэкранный режим, замена шапки и очистка. Для проверки открыть её через HTTP после `npm run build:fixture` и вызвать `await window.runChecks()` в автоматизации браузера. Коэффициент внешнего/внутреннего размера окна моделируется: тест проверяет геометрию DOM, но не заменяет визуальную проверку нативных кнопок macOS.

`tests/compact-header.html` — отдельный стенд с разметкой шапки BB 0.46. Он проверяет освобождение строки, сохранение узлов и обработчиков, меню, переименование, дополнительные действия, свободное место, разделённый экран, замену шапки и очистку. `tests/run-browser-checks.mjs` запускает оба стенда и проверяет разные размеры окна и сенсорный указатель. Перед запуском выполните `npm run build:fixture` и поднимите HTTP-сервер в `tests` на `127.0.0.1:8765`. Затем передайте файл в `bb browser-automation run <session-id> --script-file <absolute-path> --script-host <host-id> --json`.

Стенд не загружает плагин в работающее приложение. После проверки кода и согласования установки отдельно проверьте нативные меню, перетаскивание окна и размещение элементов в BB.
