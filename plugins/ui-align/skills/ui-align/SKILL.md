---
name: ui-align
description: Проверить или отладить выравнивание верхней панели BB и компактную шапку беседы.
---

`bb ui-align status` показывает последнюю геометрию из клиентского окна.

При `nativeReservation: true` и `enabled: true` значения `controlCenterY` и `targetCenterY` должны совпадать с точностью до округления. `awaitingFrontend: true` означает, что клиент ещё не прислал данные. Настройки плагина находятся в Settings → Installed plugins → UI Align; `offsetY` задаёт поправку в диапазоне −10…10 пунктов macOS.

`compactHeader` включает перенос заголовка беседы со всеми действиями в верхнюю панель, независимо от темы и настройки `enabled` (она управляет только выравниванием). По умолчанию `compactHeader` выключен. В выводе `bb ui-align status` одноимённое поле содержит `enabled`, `active`, `reason` и `availableWidth`. `active` означает успешное размещение. `not-enough-space` — оставшегося места недостаточно; `split-layout` — открыт разделённый экран; `compact-viewport` — ширина меньше 768 CSS-пикселей или сенсорный указатель; `no-title-bar` — верхняя полоса отсутствует; `unsupported-layout` — компоновка не позволяет безопасно применить фиксированное положение; `no-thread` — заголовок беседы не найден. В этих случаях сохраняется обычная шапка.

Исходники находятся в `plugins/ui-align/` репозитория `bb-plugins`. Команды разработки выполнять из каталога плагина. После изменений выполнить `npm run typecheck`, `bb plugin build`, `bb plugin reload ui-align`, затем проверить состояние командой выше. `bb plugin disable ui-align` полностью убирает коррекцию. После крупных обновлений BB проверить селектор шапки и класс, резервирующий место для нативных кнопок.

Для проверки без установки: `npm run build:fixture`, HTTP-сервер каталога `tests` на порту 8765 и `tests/run-browser-checks.mjs` через Browser Automation. Это проверка DOM/CSS на стенде; нативное окно BB проверяйте отдельно после разрешённой пользователем установки или перезагрузки.
