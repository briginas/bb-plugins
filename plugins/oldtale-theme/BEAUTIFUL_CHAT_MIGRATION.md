Этот файл хранит решения о переносе и инструкции для продолжения в новом чате.
Дата начала: 2026-10-17.

## Задача

Выбрать отдельные изменения Beautiful Chat и добавить их в Oldtale.
Сохранить цвета Oldtale и настройки шрифтов по областям.
Проверять каждое изменение после локальной установки.
Обсуждать каждый пункт отдельно с пользователем.

Beautiful Chat должен оставаться полностью отключённым во время проверки.
Не включайте его автоматически после установки Oldtale.
Не переносите остальные пункты без решения пользователя.

## Статусы

- **не обработан** — решение ещё не принято. Изменение не должно входить в локальную сборку.
- **взят** — изменение выбрано для переноса. Результаты проверки и отзыв пользователя записываются отдельно.
- **не взят** — пользователь отклонил перенос. Причина записывается в примечании.

Статус «взят» не заменяет проверку или визуальное одобрение пользователя.

## Установка и проверка

Рабочий каталог: `plugins/oldtale-theme` в этом репозитории.
Для разработки используйте локальную установку. Для опубликованной версии пользователь выбрал GitHub:

```sh
bb plugin install git:https://github.com/briginas/bb-plugins.git@main --plugin oldtale-theme --yes
bb theme set plugin:oldtale-theme:oldtale
```

При смене источника сохраните настройки и проверьте их после установки.
Если BB отказывается заменить установленный плагин, сначала изучите доступные команды замены.

Цикл локальной разработки:

```sh
bb plugin disable beautiful-chat
env -u BB_CLI npm_config_cache=/tmp/oldtale-npm-cache npm run check
bb plugin install /Users/dev.briginas/dev/bb-plugins/plugins/oldtale-theme --yes
bb theme set plugin:oldtale-theme:oldtale
```

`BB_CLI` перенаправляет запуск на CLI установленного приложения.
Его исключение использует CLI из зависимостей проекта и сохраняет закреплённую версию SDK для проверки метаданных.
Временный npm-кеш исключает запись в закрытый для песочницы каталог `~/.npm`.

После последующих изменений выполните проверку проекта и `bb plugin reload oldtale-theme`.
Проверьте, что `bb plugin list` показывает локальный источник Oldtale и отключённый Beautiful Chat.
Проверьте совпадение CSS активной темы с `themes/oldtale.css`.

Для пунктов 01 и 02 проверьте следующие состояния:

- тёмный и светлый режимы;
- пустое поле и поле с текстом;
- фокус внутри поля;
- доступную и недоступную отправку;
- остановку во время генерации;
- наведение, нажатие и настройку уменьшения движения;
- узкое окно и обычную ширину.

Не отправляйте сообщение и не останавливайте реальный запуск ради проверки оформления.
Для этих состояний используйте отдельную страницу проверки с разметкой BB.
Отдельно проверьте установленную тему через API BB и доступный интерфейс.
